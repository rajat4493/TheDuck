### Agent design choices for your review (not yet approved product behaviour)

These sit inside the approved M1.1 scope. Each could be changed in M1.2 if you disagree.

- Question bank: 11 core questions (12 if no working name was given), plus conditional follow-ups (broad user, integration down, AI wrong, AI usage). Up to 16; fixtures asked 12–14.
- A "that's very broad" challenge fires when the target user sounds like "everyone".
- Keyword hints (e.g. "patient", "AI") only pre-select a suggestion; the founder still chooses.
- Choosing an option that adds TheDuck-written text (e.g. a protection rule) says so in the option label, and the text is labelled THEDUCK-SUGGESTED + HUMAN-APPROVED.
- Acceptance criteria are generated: one per journey step, one per must-never rule and one per success check. The founder can replace them in the preview.
- Locking needs the exact statement: "I approve this product intent and want to lock it."
